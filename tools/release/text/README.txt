SHADOW THE HEDGEHOG - NATIVE PC PORT
====================================

A native PC version of Shadow the Hedgehog (Xbox, USA), made by static recompilation: the game's own code is
translated to x86-64 C++ and runs directly as a native PC program.

This download holds NO game files and NO game code. You need your own copy of the game:
  - a disc image (.iso) of the USA Xbox disc, or its extracted files.

INSTALL
  Windows: run Setup.exe, choose a folder, your .iso and (optionally) the HD texture pack zip.
  By hand: put your .iso into the assets folder and run Shadow.exe.
  Linux:   see README-Linux.txt.

FIRST START
  The game builds its code from your disc with the bundled compiler (compiler folder). This takes a few minutes,
  once, behind a progress window. If the HD texture pack is in textures\pack, it is converted once as well.

MOVING
  The whole folder is self-contained (saves are in hdd\). Move or rename it anywhere, except Program Files.

NEEDS
  Windows 10/11 64-bit, a Direct3D 12 graphics card, about 4 GB of free space.

SETTINGS
  In game: pause menu. Controls: see CONTROLS.txt.
