SHADOW THE HEDGEHOG - NATIVE PC PORT - CONTROLS
================================================

Controllers: Xbox, PlayStation and Switch controllers work automatically (plug in any time).
Keyboard:    always on, and works together with a controller.

KEYBOARD                        CONTROLLER BUTTON
--------                        -----------------
W A S D                         Left stick (move)
  hold Left Alt                   walk (half tilt)
I J K L                         Right stick (camera)
Arrow keys                      D-pad
Space                           A   (jump / confirm)
Left Shift  or  Backspace       B   (action / back)
F                               X
R                               Y
C                               Black
V                               White
Q                               Left trigger
E                               Right trigger
Enter  or  Escape               Start (pause, "press start")
Tab                             Back
Z                               Left stick click
T                               Right stick click

CHANGING KEYS
-------------
Open settings.toml beside Shadow.exe (it is written the first time the game starts), find
[keyboard_bindings] and edit the list of keys for an action, then start the game again:
    a = ["Space", "J"]          two keys for A (jump)
    black = []                  no key for Black
The options menu (F1, CONTROLS tab) shows the keys in use.
Key names: A-Z, 0-9, F2, F4-F12, Space, Enter, Escape, Tab, Backspace, LShift, RShift, LCtrl, RCtrl,
LAlt, RAlt, Up, Down, Left, Right, Insert, Delete, Home, End, PageUp, PageDown, Numpad0-Numpad9,
NumpadPlus, NumpadMinus, NumpadStar, NumpadSlash, NumpadDot, Semicolon, Equals, Comma, Minus, Period,
Slash, Backquote, LBracket, Backslash, RBracket, Quote, MouseLeft, MouseRight, MouseMiddle, Mouse4,
Mouse5.  (F1 and F3 are kept for the options menu and captures.)

To turn the keyboard off, set   keyboard = false   in settings.toml beside Shadow.exe.

OPTIONS MENU:  F1  (controller: hold BACK, press START)
--------------------------------------------------------
Up/Down select, Left/Right change, Q/E switch tabs (controller: LT/RT), mouse works too.
Display mode (fullscreen / borderless / window), resolution, V-Sync, frame rate,
render resolution (50-200%), texture filtering, HD 3D world, skip any cutscene, cutscenes at 60 FPS,
keyboard controls, FPS counter. Changes apply and save immediately (settings.toml).
